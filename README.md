# 🃏 Little Blackjack Game

A simple terminal-based Blackjack game written in C++.

## About the Project

Little Blackjack Game is a small console application developed as a final project for my Programming Language course. It brings the classic Blackjack card game to the terminal, allowing users to enjoy a simple game while interacting with a text-based interface.

The main purpose of this project was to apply and practice fundamental C++ programming concepts through a small, interactive game.

## Features

- Terminal-based gameplay
- Simple and interactive interface
- Classic Blackjack rules and mechanics

## Technologies Used

- **Language:** C++
- **Environment:** Terminal / Console

## How to Run

1. Clone the repository:
   ```bash
   git clone <repository-url>
   ```
2. Navigate to the project directory.
3. Compile the source code:
   ```bash
   g++ main.cpp -o blackjack
   ```
4. Run the game:
   ```bash
   ./blackjack
   ```

## Purpose

This project was created primarily for educational purposes as an opportunity to practice C++ programming and explore how basic programming concepts can be used to build a playable application.
